# Contributing to EMControle

Thank you for your interest in EMControle.

This project is an offline-first Flutter app for organizing treatment routines and personal records related to Multiple Sclerosis. Contributions should preserve the app's privacy and safety principles.

## Project Boundaries

Do not add:

- backend services
- authentication or accounts
- cloud sync
- cloud backup
- analytics or tracking
- export features
- charts or medical analysis
- AI diagnosis, prediction, or recommendation features

The app must not provide diagnosis, prescription, dosage recommendation, or medical advice.

## Development Setup

```sh
flutter pub get
flutter analyze
flutter test
```

## Contribution Guidelines

- Keep user data local to the device.
- Keep Portuguese copy clear, respectful, and accessible.
- Prefer simple, readable Dart and Flutter code.
- Match the existing Material 3 visual style.
- Keep changes scoped to one purpose at a time.
- Add or update tests when behavior changes.

## Medical Safety

Any text related to treatment must reinforce that users should follow their healthcare team's guidance. EMControle only organizes information already provided by professionals.
